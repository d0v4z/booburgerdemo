# Boo Burger — website demo

Demo site for Boo Burger (Monot · Batroun · Saida), built by Yalla Website.

## Pages
- `/` — home: Tray of Happiness intro, The Boo Experience, scroll menu, branches
- `/menu/` — full menu with USD + LBP prices
- `/thestory/` — Ibrahim Farchoukh's walk from Beirut to Saida

## Publish on GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, folder `/ (root)` → Save.
The site will be live at `https://d0v4z.github.io/booburgerdemo/`.

## Custom domain later
When the domain is bought: add a `CNAME` file with the domain, set it in Settings → Pages,
and change `<base href="/booburgerdemo/">` in `404.html` to `<base href="/">`.
